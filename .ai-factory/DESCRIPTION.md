# rust-examples

## Обзор
Учебный репозиторий с примерами на Rust. На данный момент содержит один крейт `tetris` — точку входа для практики разработки на Rust (сейчас в состоянии «Hello, world!»).

## Текущее состояние
- Крейт `tetris` v0.1.0, Rust edition 2024, без внешних зависимостей
- `src/main.rs` — стандартный «Hello, world!»
- Отдельный README проекта отсутствует (корневой README содержит только заголовок)

## Технологический стек
- **Язык:** Rust (edition 2024)
- **Фреймворк:** отсутствует
- **База данных:** отсутствует
- **ORM:** отсутствует
- **Интеграции:** отсутствуют

## Архитектура
Подробные архитектурные правила описаны в `.ai-factory/ARCHITECTURE.md`.
Паттерн: Слоистая (Layered Architecture)

## Замечания по архитектуре
- Корень репозитория — контейнер для набора независимых примеров-крейтов (шаблон «одна директория = один пример», аналогично `tetris/`)
- Сборка и тесты выполняются через `cargo` внутри директории каждого крейта
- `target/` — артефакты сборки, не предназначены для хранения в git
- Крейты-примеры самодостаточны: минимум зависимостей, акцент на читаемости кода

## Нефункциональные требования
- **Логирование:** на данный момент отсутствует; при появлении — через стандартную экосистему Rust (`log` + реализация, настраиваемый уровень)
- **Обработка ошибок:** идиоматичный Rust — `Result`/`?`, паники только для неисправимых состояний
- **Безопасность:** память и потокобезопасность на уровне компилятора; внешние зависимости добавлять обдуманно
