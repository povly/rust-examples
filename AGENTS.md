# AGENTS.md

> Поддерживайте этот файл при значительных изменениях структуры проекта. Это карта проекта для AI-агентов.

## Обзор проекта

Учебный репозиторий с примерами на Rust. На данный момент содержит один крейт `tetris` (Rust edition 2024) в начальном состоянии «Hello, world!».

## Технологический стек

- **Язык:** Rust (edition 2024)
- **Фреймворк:** отсутствует
- **База данных:** отсутствует
- **ORM:** отсутствует

## Структура проекта

```
rust-examples/
├── tetris/            # крейт-пример: одна директория = один пример
│   ├── Cargo.toml     # манифест крейта (без внешних зависимостей)
│   ├── Cargo.lock     # зафиксированные версии (генерируется cargo)
│   ├── src/
│   │   └── main.rs    # точка входа крейта
│   └── target/        # артефакты сборки (не хранить в git)
├── .ai-factory/       # контекст AI Factory: описание, правила, архитектура, планы
├── .opencode/         # скиллы и зависимости OpenCode
├── .codegraph/        # индекс кодовой базы для codegraph MCP
└── README.md          # заголовок проекта (наполнение через /aif-docs)
```

## Ключевые точки входа

| Файл | Назначение |
|---------------------------|------------------------------|
| `tetris/src/main.rs` | Точка входа крейта `tetris` |
| `tetris/Cargo.toml` | Манифест крейта: имя, версия, зависимости |
| `.ai-factory/config.yaml` | Конфигурация AI Factory: языки, git, пути |

## Сборка и тесты

- Сборка: `cargo build` внутри директории крейта (`tetris/`)
- Тесты: `cargo test` внутри директории крейта
- Проверка: `cargo check` внутри директории крейта

## Правила для агентов

- Разбивайте составные shell-команды на отдельные вызовы
  - Неверно: `git checkout main && git pull`
  - Верно: сначала `git checkout main`, затем `git pull origin main`
- Соблюдайте соглашения из `.ai-factory/rules/base.md`
- Коммиты и push — только по явному запросу пользователя (базовая ветка: `main`)
