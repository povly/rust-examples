# rust-examples

> Учебный репозиторий с примерами на Rust: одна директория — один самостоятельный крейт.

Набор независимых крейтов-примеров для практики разработки на Rust. Каждый пример собран по слоистой архитектуре и рассчитан на чтение кода сверху вниз.

## Быстрый старт

```bash
# Установка Rust (если ещё не установлен)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Запуск примера — из директории крейта
cd tetris
cargo run
```

Требуется Rust 1.85+ (edition 2024). В репозитории сейчас: `tetris` — начальная точка игрового примера.

## Ключевые особенности

- **Одна директория = один пример** — крейты не зависят друг от друга, каждый собирается отдельно
- **Слоистая архитектура** — `model` → `logic` → `render`, зависимости строго вниз
- **Минимум зависимостей** — учебные примеры не тянут лишнего из crates.io
- **Тесты рядом с кодом** — встроенный механизм `#[cfg(test)]`

## Пример

```bash
$ cd tetris && cargo run
Hello, world!
```
