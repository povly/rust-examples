# rust-examples

> Учебный репозиторий: десктопное приложение на Rust — окно на winit, графика на wgpu.

Практика разработки на Rust: стартовый каркас приложения на winit (событийный цикл через `ApplicationHandler`, окно) с подключённым wgpu для будущего рендеринга. Крейт лежит в корне репозитория.

## Быстрый старт

```bash
# Установка Rust (если ещё не установлен)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Запуск из корня репозитория
cargo run
```

Требуется Rust 1.85+ (edition 2024). Приложение открывает окно «Практика» размером 800×600; закрытие окна завершает программу.

## Стек

- **winit** — окно и событийный цикл (`ApplicationHandler`, `ControlFlow`)
- **wgpu** — графический бэкенд (подключён, рендеринг ещё не начат)
- **log + env_logger** — логирование: `RUST_LOG=info cargo run`

## Пример

```bash
$ cargo run
# окно «Практика» 800×600, минимальный размер 400×300, ресайз включён
```
