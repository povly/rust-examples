# Добавление примера

Новый пример — это новый независимый крейт в собственной директории корня репозитория.

## Чек-лист нового крейта

```bash
# 1. Создать крейт (имя — нижний регистр, без подчёркиваний)
cargo new my-example

# 2. Проверить, что собирается
cd my-example && cargo run && cargo test
```

Затем привести манифест и код к правилам репозитория:

- [ ] `Cargo.toml`: заполнены `name`, `version`; внешние зависимости — только при необходимости
- [ ] `src/`: до ~200 строк — один `main.rs`; дальше — модули `model/`, `logic/`, `render/` (см. [Архитектуру](architecture.md))
- [ ] Тесты — в модулях `#[cfg(test)]` рядом с кодом
- [ ] Ошибки — через `Result`/`?`; `unwrap()`/`expect()` только в тестах
- [ ] `.gitignore` корня репозитория содержит `target/`

## Игнорирование артефактов сборки

Корневой `.gitignore` должен исключать артефакты сборки всех крейтов сразу:

```gitignore
target/
```

`Cargo.lock` для бинарных крейтов-примеров хранится в git — это фиксирует воспроизводимую сборку.

## Соглашения именования

| Объект | Стиль | Пример |
|--------|-------|--------|
| Директория/крейт | нижний регистр | `my-example` |
| Файлы модулей | snake_case | `game_state.rs` |
| Типы | PascalCase | `Board`, `Piece` |
| Функции и переменные | snake_case | `try_move` |
| Константы | SCREAMING_SNAKE_CASE | `MAX_SPEED` |

Полный список соглашений — в [`.ai-factory/rules/base.md`](../.ai-factory/rules/base.md).

## Требования к среде

- Rust 1.85+ (edition 2024), установка — в [Начале работы](getting-started.md)
- Внутри крейта: `cargo build` / `cargo test` / `cargo check`
