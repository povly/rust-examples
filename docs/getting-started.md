# Начало работы

## Предварительные требования

| Инструмент | Версия | Проверка |
|------------|--------|----------|
| Rust (rustup) | 1.85+ (edition 2024) | `rustc --version` |
| Cargo | входит в поставку Rust | `cargo --version` |

Установка Rust через [rustup](https://rustup.rs):

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

## Сборка и запуск

Каждый пример — отдельный крейт в собственной директории. Команды Cargo выполняются **внутри директории крейта**:

```bash
# Запуск примера tetris
cd tetris
cargo run

# Только сборка (без запуска)
cargo build

# Быстрая проверка компиляции
cargo check
```

Ожидаемый вывод `tetris` на данном этапе:

```text
Hello, world!
```

## Тесты

Тесты запускаются той же командой внутри директории крейта:

```bash
cd tetris
cargo test
```

Тесты пишутся рядом с тестируемым кодом в модулях `#[cfg(test)]` — см. [Добавление примера](contributing.md).

## Структура директорий

```text
rust-examples/
├── tetris/        # крейт-пример
└── docs/          # эта документация
```

Артефакты сборки (`target/`) не хранятся в git и генерируются Cargo автоматически.
